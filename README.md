# Portfolio 2026

Personal portfolio built with Astro and Tailwind CSS. Static output, deployed to GitHub Pages.

## Commands

| Command | Action |
|---|---|
| `npm install` | Install dependencies |
| `npm run dev` | Start the dev server at `localhost:4321` |
| `npm run build` | Build the site to `dist/` |
| `npm run preview` | Preview the production build |

## Structure

- `src/data/` site content (projects and case study copy)
- `src/components/` UI pieces
- `src/pages/` Home and case study pages
- `assets/` screenshots, mockups, logos
